# SLL-3D

**SLL-3D** Это проект SlavaSlavyan (Святослав Моско) который представляет из себя простой движок написанный на C#.

### Цели проекта:

- Создать базовое проекцию трёхмерных фигур на экран
- Создать загрузку обьектов
- Сделать простые шейдеры
- Возможное создание онлайн режима?

Для реализации планируется использовать фреймворк **MonoGame**
