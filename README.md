# SLLE

**SLL Engine** Это проект **SlavaSlavyan** который представляет из себя простой движок написанный на C# с использованием OpenTK *(обёртка под OpenGL)*. 

### Цели проекта:

На данный момент цели проекта базовые

- Создание базового окна приложения
- Создание шейдеров
- Вывод примитивов (треугольников)
- Создание проекции трёхмерных объектов
- Вывод трёхмерных обьектов на экран

Если у меня получится вывести **ХОТЯ БЫ** базовый куб, то это будет победа. Всё же главная цель проекта это просто научится работать с OpenGL. Всё остальное будет созданно если я вообще успею, ведь времени на момент написания у меня осталось около 4 недель.

### Зависимости

Использую **.NET** версии **10.0.5**. 

Пишу на языке программирования **C# 14**

Использую библиотеку **OpenTK** версии **4.9.4**
